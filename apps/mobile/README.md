# ŞƏBƏКƏ Android

This directory is the Android wrapper configuration for the existing web app.
The Android native project is generated by Capacitor during the build pipeline.

For a local build:
1. Install Node.js, Java 21 and Android Studio/SDK.
2. From repository root run `npm install`.
3. Run `npm --prefix apps/web install`.
4. Run `npm run android:sync`.
5. Open the generated `android/` project in Android Studio and build the APK.

The GitHub Actions workflow can generate and build the Android project automatically.
